# Epping Forest Finds — Image Generation Spec

Use this file to generate each icon independently while preserving a consistent style across the whole set.

Recommended output: transparent PNG, tightly cropped. SVG can be used if the generator supports high-quality vector output.

Do not regenerate: `filter-underground`, `filter-national-rail`, `ui-filter`.

---

## Locked style block

Use this exact style block in every prompt.

```text
STYLE REFERENCE

Create a single icon for a premium outdoor navigation app called Epping Forest Finds.

Design language:
• Modern vector icon
• Inspired by Apple SF Symbols, Lucide and Phosphor
• Clean geometric construction
• Bold silhouette
• Rounded corners
• Consistent stroke weight
• Minimal internal detail
• Maximum 2 colours plus outline
• Dark forest green outline
• Muted natural fills
• Flat colour only
• No gradients
• No texture
• No hand-drawn effect
• No sticker effect
• No emoji appearance
• No cartoon styling
• No realism

Composition:
• Single centred icon
• Transparent background
• No text
• No letters
• No numbers
• No scenery
• No decorative elements
• No container shape
• No circle behind icon
• No square behind icon
• No shadow
• No glow

Sizing:
• Icon occupies 90–95% of canvas
• Extremely tight crop
• Minimal padding
• No whitespace border
• No presentation spacing
• Optimised for 20–24px display
• Production-ready UI asset

All icons in the set must appear to have been designed by the same designer and belong to the same icon family.
```

## Tree species prompt template

Use this extra tree species rule block for every tree species icon.

```text
TREE SPECIES RULES

Use a leaf-forward design.
The leaf silhouette is the primary identifier.
No trunk.
No branch.
No wood beneath the leaf.
The leaf should fill most of the icon.
Keep the shape extremely clear at 20px.
```
